OmniConvert is an offline, privacy-first utility featuring real-time unit conversions and smart bill/tip splitting.

## 🔒 Privacy Policy
Read our live [Privacy Policy](https://ojuawo.github.io/omniconvert/).

## ✨ Features
- **7 Unit Categories:** Length, Weight/Mass, Temperature, Speed, Digital Storage, Volume, Area.
- **Smart Tip & Bill Split:** Custom tip percentages, split by up to 50 people, clear per-person breakdowns.
- **100% Offline:** Zero internet permissions, instant calculations, no analytics.
- **Target SDK 36 (Android 16)**
